# 任务看板交互与布局修复（2026-09-24）

## 原因与处理
- 全局文本输入框样式使 checkbox 全宽且最小高 36px：为 checkbox 单独限定 16px，修复正式任务与识别事项两处。
- 原五列密集堆叠、没有分页：默认改为紧凑列表；分组看板保留最低列宽和内部横向滚动，增加分页、状态/甘特图筛选、搜索及排序。
- 没有全选：新增全选当前页、半选反馈、取消选择；换页或筛选清空选择，避免修改不可见任务。
- 批量处理混淆“取消勾选”和“从列表隐藏”：成功清除已处理勾选；默认切换未进甘特图筛选，可取消自动隐藏；任务不删除。
- 原回调吞掉错误且无差别刷新全系统：批量返回逐项成功/跳过结果；失败保留勾选；任务写入只刷新相关数据，已保存但刷新失败单独提示。
- 归档/识别项可被直接批量改甘特图：后端只接受有效正式任务，其他返回原因；归档记录单条修改也被拒绝。
- 进度每键提交：改为本地编辑后显式保存，按钮 loading、防重复提交、0—100 整数校验；失败保留输入。
- 非标准任务状态无对应列而消失：兼容中文与旧状态，未知值进入“待核对状态”，不擅自改数据库。
- 日期缺失不易发现：已进甘特图但缺日期时明确提示；新任务/详情默认折叠，来源仍可预览。
