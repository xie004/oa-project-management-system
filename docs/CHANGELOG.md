## 2026-08-31 - 项目内容识别与数据治理

- Tag：`data-governance-20260831`
- Commit：`31c56d5`
- 主要变更：
  - 新增统一事项身份和来源证据层，同一事项可关联多份周报、会议纪要和正式资料。
  - 新增管理员“数据治理”页面，支持重复合并、误识别归档、版本确认、权威修正和字段冲突选择。
  - 修复页码、重复页眉页脚、纯编号、Excel 表格残片和风险措施误识别；抽取结果增加页码、段落、表格和工作表行位置。
  - 智能建议按事项指纹聚合跨文件来源，模型输出执行严格 JSON 校验并保存失败原始响应。
  - 首页、任务、风险、里程碑、变更、交付物和周报统计默认过滤已归档次记录，并可查看来源时间线。
  - Wiki 和智能问答按当前有效版本过滤，同一版本组只选择一份资料作为主来源。
- 验证结果：
  - 7 项后端规则与候选聚合测试通过。
  - 后端编译和前端生产构建通过。
  - 浏览器验证数据治理后台任务动画、治理建议、来源时间线和甘特图选中样式正常。
  - 实施前数据库备份：`rollback-backups/before-data-governance-20260831/oa_project.db`。
- 回退方式：
  - 代码回退到实施前：`git checkout before-data-governance-20260831`
  - 代码回到本版本：`git checkout data-governance-20260831`
  - 数据回退前请先停止服务，再使用上述数据库备份；回退会丢失备份之后的新数据。
