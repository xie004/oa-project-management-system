# 国产化OA集成项目管理系统

这是部署在本机、可供局域网访问的 OA 集成项目管理网页系统。

## 功能

- 项目仪表盘、红黄绿状态、总体进度
- 甘特图、任务看板、里程碑时间轴
- 会议纪要、变更需求、风险问题、项目资料台账
- 文件夹监控与智能识别建议
- 项目周报汇总与 Word 导出
- 默认监控当前项目根目录，并支持按资料类型配置不同目录

## 启动

首次启动会自动创建 Python 虚拟环境、安装依赖、安装前端依赖、构建前端并启动服务。

```powershell
.\start.ps1
```

启动后，在本机或局域网浏览器访问：

```text
http://本机IP:8010
```

## 迁移

复制整个 `oa-project-management-system` 目录到新电脑或服务器即可。迁移后进入目录重新执行：

```powershell
.\start.ps1
```

如项目资料目录位置变化，可在系统的“系统设置”页面修改默认监控目录和分类监控目录。
